# Referencias de diseño

Estas capturas son documentación interna y no deben importarse desde `frontend/web` ni copiarse al bundle de producción.

## Lectura visual aplicada

- Navegación flotante y compacta con fuerte contraste.
- Headlines editoriales, grandes, de peso medio y tracking cerrado.
- Mucho espacio vertical y containers consistentes.
- Superficies casi blancas, bordes finos y sombras mínimas.
- Cards modulares con jerarquía interna y microinteracciones discretas.
- Azul reservado para acentos, estados y acciones.

`restate-inspiracion-10.png` es la única referencia de identidad de Kuentra presente en el material recibido. Para producción se deberá reemplazar el wordmark tipográfico temporal por el archivo vectorial oficial cuando esté disponible.
